# TypeScript DAY1 Project

## Setup
```bash
cd TYPESCRIPT/TS(DAY1)
npm install
```

## Build
```bash
npm run build
# or
tsc
```

## Development (Watch mode)
```bash
npm run dev
```

## Run
```bash
node dist/index.js
```

**Note:** Now `tsc .\index.ts` error is fixed. Use `tsc` (no args) or `npm run build` to compile using tsconfig.json → outputs to `dist/`.
